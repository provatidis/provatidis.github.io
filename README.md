## Local preview

Plain HTML, CSS, and JavaScript; no build step or dependencies.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765. The page follows your system theme until you choose a theme with the toggle.
